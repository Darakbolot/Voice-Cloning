# Data lokal

Hanya README ini yang dilacak Git. Isi lainnya tetap lokal:

- `audio/suwawa/`: rekaman mikrofon dan hasil sintesis.
- `models/gpt-sovits/pretrained_models/`: arsip unduhan model lama.
- `training/indonesia/stage-1/`: arsip eksperimen dan bobot tahap pertama.
- `training/indonesia/stage-2/`: log TensorBoard dan konfigurasi tahap kedua.

Model runtime GPT-SoVITS berada di `third_party/gpt-sovits/GPT_SoVITS/pretrained_models/` dan juga dikecualikan dari Git. Konfigurasi eksperimen asli masih memakai path Kaggle. Jangan mengunggah rekaman, transkrip, atau checkpoint tanpa izin.
